# Courier Payments DWH Pipeline

Проект реализует end-to-end пайплайн обработки данных доставки и расчёта выплат курьерам.

Архитектура построена по классической трёхслойной модели:

- **STG** — слой сырых данных из API
- **DDS** — детальный слой (снежинка)
- **CDM** — витрина для расчёта выплат курьерам

---

# Бизнес-задача

Необходимо построить витрину выплат курьерам, которая содержит:

- количество заказов за месяц
- сумму заказов
- средний рейтинг курьера
- комиссию компании
- сумму начислений курьеру
- чаевые
- итоговую выплату

---

# Архитектура данных

## Поток данных

API -> STG (raw JSON) -> DDS (нормализованная модель) -> CDM (витрина выплат курьерам)

---

## STG слой (сырой слой)

Хранит данные из API в формате JSON.

### Таблицы:

- `stg.api_restaurants`
- `stg.api_couriers`
- `stg.api_deliveries`

### Особенности:

- данные не трансформируются
- сохраняется полный JSON
- используется пагинация API

---

## DDS слой (детальный слой)

Модель "снежинка".

### Таблицы:

- `dds.dm_couriers` — справочник курьеров
- `dds.dm_orders` — заказы (связь с пользователями и ресторанами)
- `dds.fct_deliveries` — факты доставок
- `dds.fct_product_sales` — продажи по заказам
- `dds.dm_timestamps` — календарь

---

## CDM слой (витрина)

### Таблица:

- `cdm.dm_courier_ledger`

### Состав витрины:

- courier_id
- courier_name
- settlement_year
- settlement_month
- orders_count
- orders_total_sum
- rate_avg
- order_processing_fee
- courier_order_sum
- courier_tips_sum
- courier_reward_sum

---

---

# Особенности реализации

## 🔹 STG слой
- пагинация API (limit/offset)
- сохранение JSON
- upsert по object_id

## 🔹 DDS слой
- нормализация данных
- связывание сущностей
- добавление курьера в модель заказов

## 🔹 CDM слой
- расчет выплат по бизнес-логике
- учет рейтинга курьера
- расчет комиссии и чаевых
- агрегация по месяцам

---

# Бизнес-логика выплат

| Рейтинг | Процент | Мин. выплата |
|--------|--------|-------------|
| < 4.0  | 5%      | 100         |
| 4–4.5  | 7%      | 150         |
| 4.5–4.9| 8%      | 175         |
| ≥ 4.9  | 10%     | 200         |
